# MediVault

Your family's complete medical history. One tap away.

## About

MediVault is a secure family medical records management platform.

The goal is to help families organize, store, and securely share medical records without relying on physical files or scattered WhatsApp chats.

## Tech Stack

### Frontend
- React
- Vite

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### File Storage
- AWS S3

### Authentication
- JWT

### Validation
- Zod
